## Следующие шаги для завершения передачи

📖 **Полная инструкция:** `docs/TRANSFER_INSTRUCTIONS.md`

### 1. Передача доступов заказчику

1. Заказчик создаёт GitHub аккаунт
2. Добавить заказчика как Collaborator в репозиторий
3. Перенастроить GitHub OAuth App на заказчика
4. Передать доступы к домену и VPS Timeweb
5. Передать доступ к Telegram-боту (или добавить в чат)

### 2. Яндекс.Метрика (рекомендуется)

1. Создать счётчик на metrika.yandex.ru
2. Добавить код в `src/layouts/Layout.astro`
3. Настроить цели на отправку формы

### 3. Обучение работе с CMS

Провести краткий созвон для демонстрации:
- Как войти в CMS через GitHub
- Как редактировать контент
- Как добавлять новые записи
- Как загружать изображения

## Как работает деплой

1. Изменения пушатся в `main` ветку на GitHub
2. GitHub Actions автоматически собирает сайт
3. Собранные файлы копируются на VPS через rsync
4. Nginx отдаёт статические файлы

**Файл workflow:** `.github/workflows/deploy-vps.yml`
