## Что требуется от заказчика

### 1. Telegram-бот (обязательно для заявок)

**Время:** ~15 минут

1. Создать бота через @BotFather в Telegram
2. Получить Chat ID
3. Развернуть функцию в Yandex Cloud

📖 **Инструкция:** `cloud-function/README.md`

### 2. VPS в РФ (для продакшена)

**Время:** ~1 час

1. Арендовать VPS (~300-500₽/мес)
2. Установить Nginx
3. Настроить SSH-деплой
4. Настроить SSL

📖 **Инструкция:** `docs/DEPLOY_GUIDE.md`

### 3. Домен

1. Зарегистрировать домен .ru
2. Настроить DNS на VPS
3. Обновить `astro.config.mjs`

### 4. Яндекс.Метрика (рекомендуется)

1. Создать счётчик
2. Добавить код в `Layout.astro`
3. Настроить цели

## Доступ к CMS

**URL:** `https://ваш-домен.ru/admin/`

**Первоначальная настройка:**
1. Включить Netlify Identity в настройках Netlify (если используете Netlify)
2. Или настроить Git Gateway для GitHub авторизации

**Что можно редактировать:**
- Услуги
- Курсы
- Отзывы
- Эксперты
- FAQ
- Настройки сайта
