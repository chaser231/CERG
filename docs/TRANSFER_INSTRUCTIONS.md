# Инструкция по передаче проекта ЦЕРГ

## Что передаётся заказчику

| Ресурс | Что нужно сделать |
|--------|-------------------|
| GitHub | Заказчик создаёт аккаунт, получает доступ к репо |
| Домен cerh.pro | Передать логин/пароль от регистратора |
| VPS Timeweb | Передать доступ к панели управления |
| Telegram-бот | Передать токен бота или добавить заказчика в чат |
| GitHub OAuth | Перенастроить на аккаунт заказчика |

---

## 1. GitHub — для заказчика

### Создание аккаунта (если нет)

1. Перейти на https://github.com/signup
2. Ввести email заказчика
3. Придумать пароль
4. Выбрать username (например: cerg-center)
5. Подтвердить email

### После создания аккаунта

Сообщить разработчику username, чтобы он:
- Добавил как Collaborator в репозиторий
- Перенастроил GitHub OAuth App

---

## 2. GitHub OAuth — для разработчика

После того как заказчик создаст GitHub аккаунт:

### Вариант A: Перенести OAuth App на аккаунт заказчика

1. Зайти в https://github.com/settings/developers
2. Найти OAuth App "CERG CMS" (или как называется)
3. Нажать "Transfer ownership"
4. Ввести username заказчика
5. Заказчик подтверждает трансфер

**После трансфера заказчику нужно:**
- Запомнить Client ID и Client Secret
- Передать их для обновления на VPS (oauth-server)

### Вариант B: Заказчик создаёт новый OAuth App

1. Зайти в https://github.com/settings/developers
2. Нажать "New OAuth App"
3. Заполнить:
   - Application name: `CERG CMS`
   - Homepage URL: `https://cerh.pro`
   - Authorization callback URL: `https://cerh.pro/oauth/callback`
4. Нажать "Register application"
5. Скопировать Client ID
6. Нажать "Generate a new client secret"
7. Скопировать Client Secret

**После этого разработчик обновляет переменные на VPS:**
```bash
ssh user@cerh.pro
# Обновить переменные в конфиге oauth-server
nano /path/to/oauth-server/.env
# GITHUB_CLIENT_ID=новый_id
# GITHUB_CLIENT_SECRET=новый_secret
# Перезапустить сервис
pm2 restart oauth-server
```

## 3. Репозиторий GitHub — для разработчика

Добавить заказчика как Collaborator:

1. Зайти в https://github.com/chaser231/CERG/settings/access
2. Нажать "Add people"
3. Ввести username заказчика
4. Выбрать роль "Admin" (полный контроль)
5. Отправить приглашение

Заказчик получит email и должен принять приглашение.

---

## 4. Домен cerh.pro

Передать заказчику:
- Логин от регистратора (NIC.ru / REG.RU / другой)
- Пароль
- Напомнить о продлении (дата истечения)

**Что заказчик должен знать:**
- Не менять DNS записи без необходимости
- A-запись указывает на IP VPS
- Продлевать домен до истечения срока

---

## 5. VPS Timeweb

### Передать доступ к панели

Два варианта:

**A) Передать текущий аккаунт:**
- Логин
- Пароль
- Сменить email на email заказчика

**B) Добавить заказчика как пользователя:**
1. Зайти в панель Timeweb
2. Настройки → Пользователи
3. Добавить нового пользователя с email заказчика

**Что заказчик должен знать:**
- Оплата ~300-500₽/мес
- Не выключать сервер
- При проблемах — обращаться в поддержку Timeweb

---

## 6. Telegram-бот

### Вариант A: Передать бота целиком

Передать заказчику:
- Bot Token от @BotFather
- Инструкцию как получить новый токен если нужно

### Вариант B: Добавить заказчика в чат

Если заявки приходят в группу/канал:
- Добавить заказчика в этот чат
- Дать права администратора

### Вариант C: Создать новый чат для заказчика

1. Заказчик создаёт группу в Telegram
2. Добавляет бота в группу
3. Разработчик обновляет CHAT_ID в Cloud Function

---

## 7. Яндекс.Метрика (если настроена)

Передать доступ:
1. Зайти в https://metrika.yandex.ru
2. Настройки счётчика → Доступ
3. Добавить email заказчика как владельца
